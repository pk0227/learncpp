=================================================================
📘 C++ FIXED-SIZE ARRAYS (STD::ARRAY & C-STYLE ARRAYS)
=================================================================

    🔹 1 — STD::ARRAY BASICS
    -------------------------------------------------------------
        #include <array>
        std::array<int, 5> a{};  // Fixed size (must be constexpr)

        Fixed vs Dynamic:
            • std::array / C-style: Fixed size (compile-time).
            • std::vector: Dynamic (runtime resizing).

        ✅ Use std::array for constexpr; std::vector for non-constexpr.

        Length Must Be Constexpr:
            std::array<int, 7> a{};           // Literal
            constexpr int len{8};
            std::array<int, len> b{};         // Constexpr variable
            std::array<int, max_colors> c{};  // Enumerator

        Zero-Length std::array:
            • Allowed but contains no data.
            • operator[] is UB.
            • Use empty() to check.

    🔹 2 — INITIALIZATION
    -------------------------------------------------------------
        Aggregate Initialization:
            std::array<int, 5> a{1, 2, 3, 4, 5};  // Fully initialized
            std::array<int, 5> b{1, 2};           // Rest value-initialized (0)
            std::array<int, 5> c{};               // All zeros (preferred)

        ⚠️ Missing braces → default-init (uninitialized for int).

        Const/Constexpr:
            const std::array<int, 5> a{2, 3, 5};      // Read-only
            constexpr std::array<int, 5> b{2, 3, 5};  // Compile-time

        ✅ constexpr support is key advantage over std::vector.

    🔹 3 — CTAD & STD::TO_ARRAY
    -------------------------------------------------------------
        CTAD (C++17):
            constexpr std::array a{9, 7, 5};  // std::array<int, 3>

        std::to_array (C++20):
            auto a = std::to_array<int>({9, 7, 5});  // Omit length
            auto s = std::to_array<short>({9, 7});    // Force type

        ⚠️ std::to_array creates temporary → less efficient.
        ✅ Prefer direct std::array with CTAD.

    🔹 4 — LENGTH & INDEXING
    -------------------------------------------------------------
        Length Type: std::size_t (Template parameter N)

        Getting Length:
            a.size()        // size_type (std::size_t)
            std::size(a)    // C++17, std::size_t
            std::ssize(a)   // C++20, signed (std::ptrdiff_t)

        Indexing:
            a[2]            // No bounds checking (UB if out of range)
            a.at(2)         // Runtime bounds checking (throws)
            std::get<2>(a)  // Compile-time bounds checking (C++11)

        ✅ Use std::get for compile-time safety with constexpr indices.

        Constexpr Length (Pre-C++23 Caveat):
            • size() returns constexpr value on non-ref objects.
            • Passing by reference breaks constexpr (language defect).
            • Workaround: Use template parameter N.

    🔹 5 — PASSING & RETURNING
    -------------------------------------------------------------
        ❌ Pass by value → expensive copy.
        ✅ Pass by const reference:
            void func(const std::array<int,5>& a);

        Function Template (Generic):
            template<typename T, std::size_t N>
            void func(const std::array<T, N>& a);

            // C++20: Use auto for N
            template<typename T, auto N>  
            void func(const std::array<T, N>& a);

        Static Assert on Length:
            template<typename T, std::size_t N>
            void printElement3(const std::array<T, N>& a) {
                static_assert(N > 3);  // Compile-time check
                std::cout << a[3];
            }

        Returning std::array:
            • By value: Simple, but copies all elements.
            • Via out-parameter: More efficient for large arrays.
            • ✅ Consider std::vector for large/move-capable data.

    🔹 6 — ARRAYS OF STRUCTS (DOUBLE BRACES)
    -------------------------------------------------------------
        Assignment (Single Braces):
            houses[0] = {13, 1, 7};  // ✅ OK

        Initialization with Explicit Type:
            std::array houses{House{13, 1, 7}, House{14, 2, 5}};  // ✅ OK

        Initialization WITHOUT Explicit Type (DOUBLE BRACES):
            std::array<House, 3> houses{{  // Outer array
                {13, 1, 7},                // Inner C-style array
                {14, 2, 5}
            }};

        Why Double Braces?
            • std::array is aggregate with internal C-style array.
            • Outer {} → std::array object.
            • Inner {} → C-style array member.

        Brace Elision:
            • Scalars (int) allow single braces.
            • Structs/arrays require double braces (unless type specified).

    🔹 7 — ARRAYS OF REFERENCES (STD::REFERENCE_WRAPPER)
    -------------------------------------------------------------
        ❌ Direct references illegal:
            std::array<int&, 2> arr;  // Error

        ✅ Use std::reference_wrapper:
            #include <functional>
            std::array<std::reference_wrapper<int>, 3> arr{x, y, z};

        Access:
            arr[1].get() = 5;   // Modify referenced value
            std::cout << arr[1]; // Implicit conversion to int&

        Helpers (C++11):
            auto r = std::ref(x);    // reference_wrapper<int>
            auto cr = std::cref(x);  // reference_wrapper<const int>

    🔹 8 — C-STYLE ARRAYS
    -------------------------------------------------------------
        Declaration:
            int arr[30]{};  // 30 elements, value-initialized

        Rules:
            • Length ≥ 1, must be constexpr.
            • Zero-length illegal (except heap-allocated).

        Initialization:
            int a[5]{1, 2, 3};  // Rest value-initialized (0)
            int b[5]{};         // All zeros
            int c[5];           // ⚠️ Uninitialized (avoid)

        Omit Length:
            int primes[]{2, 3, 5, 7};  // Compiler deduces size 5
            ✅ Prevents size/initializer mismatch.

        ❌ No Assignment:
            arr = {1, 2, 3};  // Error (use element-wise or std::copy)

        Getting Length:
            std::size(arr)      // C++17
            std::ssize(arr)     // C++20, signed
            sizeof(arr)/sizeof(arr[0])  // OLD, breaks after decay

    🔹 9 — ARRAY DECAY (CRITICAL)
    -------------------------------------------------------------
        - C-style array → pointer to first element (loses size info).

        Function Parameter:
            void func(int arr[1000]) {}  // Actually int* arr

        Why:
            • Avoids expensive copy.
            • Works with any length.

        ⚠️ Size Ignored:
            int small[2]{};
            func(small);  // Compiles (no error, UB if accessing arr[999])

        Decay Exceptions (No Decay):
            • sizeof(arr), typeid(arr)
            • &arr (address of array)
            • Passed by reference

        ✅ Prefer Modern Alternatives:
            • std::array<T, N>& (fixed size, compile-time safe)
            • std::span<T> (C++20, size-aware view)
            • std::vector<T>& (dynamic size)

    🔹 10 — WORKING AROUND DECAY
    -------------------------------------------------------------
        Pass Length Separately:
            void func(const int arr[], int length);

        ⚠️ Runtime-only validation, sign conversion issues.

        Sentinel Value:
            int scores[]{95, 87, -1};  // -1 marks end

        ⚠️ Missing sentinel → UB. Requires invalid value.

        ✅ Modern: Avoid C-style arrays in function interfaces.

    🔹 11 — POINTER ARITHMETIC
    -------------------------------------------------------------
        int arr[]{9, 7, 5};
        int* p = arr;  // Points to arr[0]

        p + 1   // Address of arr[1]
        ++p     // Move to next element
        p - 1   // Previous element

        Subscripting = Pointer Arithmetic:
            arr[i]  ≡  *(arr + i)
            p[i]    ≡  *(p + i)

        Relative Indexing:
            const int* p = &arr[3];
            p[0]   // Current element
            p[1]   // Next element
            p[-1]  // Previous element

        Traversal (Range-Based For Under the Hood):
            const int* begin = arr;
            const int* end = arr + std::size(arr);
            for (; begin != end; ++begin)
                std::cout << *begin;

        ⚠️ UB: Pointer arithmetic outside array bounds.

    🔹 12 — C-STYLE STRINGS
    -------------------------------------------------------------
        char str[]{"hello"};  // 6 chars (includes \0)

        - Null-terminated (\0).
        - Decays to char* or const char*.

        Operations (#include <cstring>):
            strlen(s)              // Length (excludes \0)
            strcmp(s1, s2)         // Compare (0 if equal)
            strcpy(dest, src)      // ⚠️ Unsafe (overflow risk)
            strncpy(dest, src, n)  // Safer (still risky)

        Input:
            char input[255];
            std::cin.getline(input, std::size(input));

        ✅ Prefer std::string or std::string_view.
        ⚠️ Only use C-style strings for legacy C APIs.

    🔹 13 — BEST PRACTICES
    -------------------------------------------------------------
        ✅ Use std::array for constexpr fixed-size arrays.
        ✅ Use std::vector for dynamic arrays.
        ✅ Use std::string/std::string_view for strings.
        ✅ Use std::reference_wrapper for arrays of references.
        ✅ Use std::get<I> for compile-time bounds checking.
        ✅ Use double braces for std::array of structs (without explicit type).
        ✅ Use std::span (C++20) for size-aware array views.
        ❌ Avoid C-style arrays (except global constexpr data).
        ❌ Avoid array decay (prefer modern containers).
        ❌ Avoid raw C-string manipulation.
