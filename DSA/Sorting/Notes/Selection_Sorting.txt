0) WHAT IS SELECTION SORT?
══════════════════════════════════════════════════════════
• Selection Sort is a comparison-based sorting algorithm
• It repeatedly SELECTS the smallest (or largest) element
• Places it at its correct position
• Divides the array into:
  - Sorted part (LEFT)
  - Unsorted part (RIGHT)


══════════════════════════════════════════════════════════
1) CORE IDEA (INTUITION)
══════════════════════════════════════════════════════════
• Find the minimum element in the unsorted portion
• Swap it with the first unsorted element
• Expand the sorted region by one element
• Repeat until array is sorted


══════════════════════════════════════════════════════════
2) VISUAL WALKTHROUGH (STEP-BY-STEP)
══════════════════════════════════════════════════════════

Initial array:
[ 64, 25, 12, 22, 11 ]

Pass 1:
• Minimum in entire array = 11
• Swap 11 with 64

[ 11 | 25, 12, 22, 64 ]

Pass 2:
• Minimum in remaining = 12
• Swap 12 with 25

[ 11, 12 | 25, 22, 64 ]

Pass 3:
• Minimum in remaining = 22
• Swap 22 with 25

[ 11, 12, 22 | 25, 64 ]

Pass 4:
• Minimum in remaining = 25
• Already in correct position

FINAL SORTED ARRAY:
[ 11, 12, 22, 25, 64 ]


══════════════════════════════════════════════════════════
3) KEY OBSERVATION
══════════════════════════════════════════════════════════
• Selection Sort performs MINIMUM number of swaps
• Exactly (n - 1) swaps in all cases
• Number of comparisons remains the same regardless of input


══════════════════════════════════════════════════════════
4) BASIC ALGORITHM (PSEUDOCODE)
══════════════════════════════════════════════════════════
for i = 0 to n-2
    min_index = i
    for j = i+1 to n-1
        if arr[j] < arr[min_index]
            min_index = j
    swap(arr[i], arr[min_index])


══════════════════════════════════════════════════════════
5) SELECTION SORT – C++ IMPLEMENTATION
══════════════════════════════════════════════════════════

#include <iostream>
#include <vector>
using namespace std;

void selectionSort(vector<int>& arr)
{
    int n = arr.size();

    for(int i = 0; i < n - 1; i++)
    {
        int minIndex = i;

        for(int j = i + 1; j < n; j++)
        {
            if(arr[j] < arr[minIndex])
                minIndex = j;
        }

        swap(arr[i], arr[minIndex]);
    }
}

6) TIME COMPLEXITY (STEP-BY-STEP)
══════════════════════════════════════════════════════════

► BEST CASE
Condition:
• Already sorted array

Behavior:
• Still scans entire unsorted portion
• Comparisons do NOT reduce

Comparisons:
(n - 1) + (n - 2) + ... + 1

Time Complexity:
O(n²)


► AVERAGE CASE
Condition:
• Random input

Behavior:
• Same number of comparisons
• Swap once per pass

Time Complexity:
O(n²)


► WORST CASE
Condition:
• Reverse sorted array

Behavior:
• Same number of comparisons
• Swap once per pass

Time Complexity:
O(n²)


══════════════════════════════════════════════════════════
7) SPACE COMPLEXITY
══════════════════════════════════════════════════════════
• Sorting is done IN-PLACE
• Only constant extra memory used

Space Complexity:
O(1)


══════════════════════════════════════════════════════════
8) STABILITY (IMPORTANT INTERVIEW POINT)
══════════════════════════════════════════════════════════
• Selection Sort is NOT STABLE
• Swapping can change relative order of equal elements

Example:
[ 2a, 2b, 1 ]
→ after sorting → [ 1, 2b, 2a ]


══════════════════════════════════════════════════════════
9) ADAPTIVENESS
══════════════════════════════════════════════════════════
• Selection Sort is NOT adaptive
• Performance does NOT improve for sorted or nearly sorted input

══════════════════════════════════════════════════════════
11) WHEN SHOULD YOU USE SELECTION SORT?
══════════════════════════════════════════════════════════
✓ When swap cost is very high
✓ Memory-constrained systems
✓ Small datasets
✓ Simple and predictable behavior required


══════════════════════════════════════════════════════════
12) WHEN SHOULD YOU NOT USE IT?
══════════════════════════════════════════════════════════
✗ Large datasets
✗ Performance-critical systems
✗ When stability is required


══════════════════════════════════════════════════════════
13) INTERVIEW ONE-LINER
══════════════════════════════════════════════════════════
Selection Sort repeatedly selects the minimum element from
the unsorted portion and places it in its correct position.
It performs O(n²) comparisons in all cases, uses O(1) space,
and is not stable or adaptive.
