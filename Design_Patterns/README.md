# 📐 Modern C++ Design Patterns

## Welcome to the Senior Architect's Design Workshop

This repository contains a curated collection of Design Patterns implemented in **Modern C++ (C++20)**. 
It is structured to take you from standard OOP patterns to high-performance System Architecture patterns required for Senior/Principal Engineer roles.

**[👉 Open the Learning Roadmap](Design_Patterns_Roadmap.md)**

### Module Philosophy
1.  **Modern C++ First**: No `new`/`delete`. We use `std::unique_ptr`, `std::shared_ptr`, and Concepts.
2.  **Thread Safety Default**: Patterns are discussed in the context of multi-threaded environments.
3.  **Performance Focused**: We prefer Compile-time polymorphism (Templates/CRTP) where possible.
